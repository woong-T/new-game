# Game Brief: 별의 용사 키우기

## In your words
간단한 키우기류 게임
기본용사부터 시작하여 (고체,유체,천체)의 세가지 속성을 고르고 각 속성별 2개의 1차직업
 각 직업별 2차직업까지 이어지는 강화,성장
우주의 천체들을 의인화한 동료들을 수집하여 같이 강해지는 형식

1. Combat: 탭 없이
2. Getting companions: 둘다 (보스 처치 합류 + 별가루 소환)
3. Companion role: 모두 (자동 공격 + 같은 속성 시너지 + 중복 별 승급)
4. Rebirth: 환생은 나중에 추가
5. Feel: 기본
6–8. Look, challenge/goal, slice: 나머지도 다 기본으로

**Pitch:** 작은 기본 용사가 고체·유체·천체 중 한 길을 골라 전직하고, 의인화된 행성 동료들과 함께 자동 전투로 우주를 거슬러 올라가 빅뱅을 쓰러뜨리는 방치형 성장 게임.

**Genre:** idle-incremental + companion collection

**Controls:** 마우스 클릭만 — 강화 버튼, 전직 선택, 소환, 동료 편성. 전투는 손대지 않음.

**Question:** 전직·강화·동료 수집이 맞물려 "다음 보스를 넘고 싶다"는 마음이 15~20분 이어지는가? *(inferred (strong))*

**Hooks:** 속성 3 → 1차 6 → 2차 6으로 갈라지는 전직 트리 + 같은 속성 천체 동료를 모을수록 붙는 시너지.

## Look and references
- Look: 깊은 남보라 우주 배경 위 네온 벡터. 속성 색 — 고체 호박/주황, 유체 청록/하늘, 천체 보라/금. 동료는 행성을 머리·몸으로 한 작은 캐릭터(토성은 고리 모자, 혜성은 꼬리 망토). 처치 시 별빛 파티클과 떠오르는 숫자. every figure drawn, no emoji, no plain circles. *(provisional)*
- References: none
- View: 2D · Camera: static — 위쪽 전투 무대, 아래쪽 강화·동료 패널. *(provisional)*

## First minute
기본 용사가 첫 별 몬스터를 저절로 때려잡고 별가루가 오른다. 약 10초 뒤 "공격력 강화" 버튼에 불이 들어오고, 누르면 데미지 숫자가 눈에 띄게 커진다. 약 30초에 스테이지 5 미니보스 "떠돌이 소행성"을 잡으면 첫 동료 루나(달)가 합류해 화면에 나타나 같이 공격하고 초당 데미지가 뛴다. 1분쯤 별가루가 소환 1회 비용에 닿아 소환 버튼이 반짝인다.

## Challenge
3~5분쯤 스테이지 10 첫 보스 "적색거성": 30초 안에 못 잡으면 이전 웨이브로 밀려난다(잃는 것 없음, 사냥하며 강화). 레벨 10에 1차 전직(속성 선택)이 열려 보스를 넘는 열쇠가 된다. 스테이지 30 보스쯤엔 2차 전직이 필요하고, 스테이지 50에 최종 보스 빅뱅 *(provisional)*.

## Core loop
- 자동 전투로 별가루·경험치 획득
- 별가루로 용사 강화(공격력·공격속도·치명타) 또는 동료 소환
- 보스 처치 → 천체 동료 합류, 레벨 도달 → 전직
- 더 강해져 다음 보스로; 막히면 사냥하며 강화

## Goal & fail state
- 목표: 2차 전직 후 스테이지 50 최종 보스 "빅뱅" 처치 *(provisional)*
- 실패: 보스 제한시간 초과 시 웨이브 후퇴, 영구 손실 없음 *(provisional)*

## Features
- [x] 자동 전투 + 스테이지 진행, 4 enemy kinds, each attacking differently (돌진형·방패형·분열형·원거리형), 10스테이지마다 보스
- [x] 용사 강화 3종 — 살 때마다 오르는 가격, 버튼에 가격과 증가량 표시
